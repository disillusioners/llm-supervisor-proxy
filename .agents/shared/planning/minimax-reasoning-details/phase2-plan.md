# Phase 2: Response-Side Translation

## Objective

Translate MiniMax's wire-format `reasoning_details` (array of typed entries) on the response side into the OpenAI-compatible per-message `reasoning_content` string on:
1. **Non-stream** responses on EXTERNAL paths (race-external, ultimate-external) using the translator's `TranslateNonStreamResponseBody` / `TranslateNonStreamResponseBytes` variants. **INTERNAL paths (race-internal, ultimate-internal) extract at `pkg/providers/openai.go`'s `extractNonStreamContent` / response-assembly per D2 — translator is NOT invoked on internal non-stream paths.**
2. **Stream SSE** responses on EXTERNAL paths (race-external, ultimate-external) using the translator's per-stream `StreamTranslator.ChunkBytes`. **INTERNAL paths emit `thinking` StreamEvents directly from `pkg/providers/openai.go`'s stream parser per D2 — the existing `case "thinking"` handlers at `race_executor.go:509` and `handler_internal.go:264` consume them; translator's `ChunkBytes` is NOT invoked on internal stream paths.**

Strip `reasoning_details` from the response before writing to the client (R11). Preserve upstream chunk ordering and tool-call / reasoning interleaving (R5, R10). Maintain byte-identical behavior on non-MiniMax or non-flagged requests (R1, Invariants #1-#6). **Single-winner rule (D2):** on both path families, when upstream emits both `reasoning_details` and `reasoning_content`, `reasoning_details` WINS. On typed/internal paths this is applied at extraction time (openai.go ignores `reasoning_content` when `reasoning_details` is present); on byte/external paths this is applied translator-side (unconditional H2 dedup via `strings.Index` containment). Consistent outcome. **Dedup** entries that are contained in the existing `reasoning_content` (H2) at extraction time on typed paths, translator-side on byte paths. **Log-and-strip** unknown `reasoning_details` types and missing-`text` entries (H3, H7). **Stream translator is error-free by construction** (Q1.5; §6.1).

## Prerequisites

- Phase 1 complete: `pkg/proxy/translator/minimax.go` exists with the §2.3 API set (`TranslateRequest{Body,Bytes}`, `TranslateMessagesReasoning`, `InjectReasoningSplit`); the dual flag mechanism (rc + parameter) is in place; header strip on ultim-ext is in place.
- Translator module's response-side API is documented: `TranslateNonStreamResponseBody(map[string]any) error`, `TranslateNonStreamResponseBytes([]byte) ([]byte, error)` — **D2 — `TranslateNonStreamResponseTyped(*providers.ChatCompletionResponse) error` is REMOVED from the API**; the two internal `Encode(resp)` sites (`pkg/proxy/internal_handler.go:117` + `pkg/ultimatemodel/handler_internal.go:71`) get `ReasoningContent` populated directly by `pkg/providers/openai.go`'s `extractNonStreamContent` / response-assembly (P2-1a), not by any translator call; `type StreamTranslator struct{...}` with `NewStreamTranslator()` and `ChunkBytes(line []byte) (stripped []byte, emitted [][]byte, err error)` — `err` is never fatal (always `nil`; anomalies log-and-passthrough per §6.1).
- Streaming reconstruction algorithm documented in `technical-analysis.md:265-289`: per-entry emission in array order; text→reasoning_content; strip reasoning_details; stateless default; per-`(streamID, choice_index)` state opt-in via the `StreamTranslator` instance.
- Architecture §2.4 thread-safety: `StreamTranslator` is single-goroutine-per-stream (loops are `for event := range eventCh` — `race_executor.go:364`, `handler_internal.go:165`; read-line loop — `handler_external.go:222`, `race_executor.go:1063`). Document "not goroutine-safe" in godoc.

## Exit Criterion

Phase 2 is DONE when **all** of the following hold simultaneously:

1. `go build ./...` and `go vet ./...` pass with no warnings introduced.
2. Existing unit tests pass without modification (backward-compat invariant #2 + #4).
3. New unit tests for P2-1, P2-2, P2-3, P2-6, P2-8, P2-9 pass (response translation + `StreamTranslator` + map-vs-struct handling + `extractEntryText` + format-drift counter).
4. New unit tests for P2-10 pass (8 negative-case byte-identical assertions: 4 non-stream + 4 stream); ultim-ext sites are the strictest invariant.
5. Drift trap check (P3-3 AST-based) passes — no `reasoning_details`/`reasoning_split` mutations outside `translator/` in the 4 call-site files.
6. Tool-call / reasoning interleaving boundary is documented in translator godoc (P2-7) and verified by P3 e2e test.
7. **No `Reset()` method exists on `StreamTranslator`** (compile-time + grep guard); each stream-loop scope constructs its own `NewStreamTranslator()`; per-stream-lifetime guard test passes.

Once Phase 2 exits, Phase 3 can begin (it depends on Phase 1 + Phase 2 artifacts being merged).
